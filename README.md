# Radius Recon — public site

The Support and Privacy Policy pages Apple requires for the App Store
listing, served by GitHub Pages at
<https://codecasa-radiusrecon.github.io/>.

- `support.html` — Support URL in App Store Connect
- `privacy.html` — Privacy Policy URL in App Store Connect
- `index.html` — landing page linking to both

**Edit the source, not this repo.** These files are copied from `Docs/Web/`
in the private app repo, which is the source of truth; changing them here
puts the two out of step. Keep `privacy.html` in step with
`Docs/AppStore/privacy-policy.md` as well — the markdown is the canonical
text, the HTML is its published form.

Both URLs must stay reachable for as long as the app is on sale. Apple
re-checks them at review.
